# Example documents

Please add here, **anonymised** (no client names, addresses, permit numbers or people):

1. A previous **BEPO report** (`.docx` or `.pdf`), ideally one with a few tekortkomingen and
   opmerkingen.
2. The **blank BEPO template** (Corcon bv, tables T0–T20).
3. Optionally: a program export as it is used today to build the report.

These are used to check that section codes, item names and the export (M3) match the real
report 1:1, and later to build the automatic "vorige keuring" import.
