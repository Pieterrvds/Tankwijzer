# VLAREM II source text

Put the official text of VLAREM II **hoofdstuk 5.17** and **bijlagen 5.17.x** here (plain text
or Markdown, one file per article group or annex, e.g. `5.17.4.1.md`, `bijlage-5.17.3.md`).

The AI features (M4/M5) retrieve passages from these files and always show the article and
the passage they used. Without this text, the app can only cite the article numbers stored
in the rules.
